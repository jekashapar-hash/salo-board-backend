# 🛠 Workflow: Перевірка та виправлення (Fix)

Цей workflow призначений для забезпечення якості коду та відповідності архітектурним стандартам проекту.

## 📋 Кроки:

1. **Пріоритезація та виправлення**
   * Розділіть помилки на категорії:
     * **Легкі**: відсутні анотації, прості перевірки на `None` (guards), невідповідність імен.
     * **Важкі**: складні дженерики, помилки в логіці, кругові імпорти.
   * Починайте виправлення з легких помилок.

2. **Циклічне виправлення до результату "Нуль"**
   * Після кожної групи виправлень повторюйте крок 1.
   * Продовжуйте процес, доки `uv run ruff check` не покаже 0 діагностик.

3. **Фінальна перевірка та запуск**
   * Коли помилок типізації не залишиться, запустіть:
   * // turbo
   * `uv run ruff check . --fix ; uv run ruff format . `

4. **Оновлення бази знань**
   * Додайте виявлені пастки (Common Pitfalls) до документації проекту.
